# 验证基线与验收计划

## 真实只读已验证

- 受支持 Chrome 工具复用用户的 Canvas 与出版社登录会话。
- 作业页面读取题号、满分、截止时间、评分入口；SpeedGrader 学生选择器33人，其中22项未计分、11项未提交（当时快照，正式运行需刷新）。
- 题库第5页识别两个二维码，通过位置和标签选择底部“习题一答案”。
- 出版社资源页登录后显示答案；临时预览失效后返回资源原页生成新链接，全屏成功。
- 相关官方答案位于第1至3页，均可视读；页码可通过点击输入框、全选、输入、回车切换。答案共4页，能定位到4/4；不把无关末页定位当成详细校对。
- 学生样本A：1份PDF共5页，封面后第2页是题1/2，第3页题6/7/8，第4页题10/11/12，第5页题15。逐页实际查看；无分数或评论写入。
- 学生样本B：两个PDF附件，各1页；分别点击预览确认内容改变。单页可能超长，正式核对需要缩放或滚动到底。这里只演练多附件切换，没有给该生作业评级。
- 未提交样本显示“该学生没有提交此作业的文件”，前一份预览消失。

## 遇到的限制

- 单文件下载跳转学校对象存储时曾出现ERR_BLOCKED_BY_CLIENT。没有绕过；Canvas内嵌预览可作为正式的读取路径。原始文件下载/批量ZIP未验证成功。
- PDF页码先更新，页面内容可能稍后更新；看实际题号和图像确认，不只看页码。
- 扫描答卷字数为0但有完整内容。
- 评分框、评论框和评论提交按钮已定位；分数实际保存触发方式、评论实际持久化、成绩发布均未在真实课程中测试。

## 本地模拟的定位

本地演练台仅验证虚构结果的计算、填写、分别保存、刷新回读、重复执行跳过、人工修改冲突及版本变化。它不是 Canvas 的复制实现，不证明真实平台的网络行为、自动保存语义或权限。

首次正式写回时，只处理一条用户授权结果并离开重进回读；验证后再扩大。当前流程 可用于只读演练及建议流程，真实写回必须保留此验收门槛。

## 首次真实写回验收

1. 选取一条明确授权的实际批改结果。
2. 核对学生、提交版本、已有分数和评论。
3. 确认分数的真实保存触发方式，写入后切走再返回验证。
4. 按要求填写并提交评论，返回页面确认评论存在且仅一条。
5. 记录分数与评论各自的成功状态。未知结果先回读，禁止盲目重试。
6. 首条通过后才扩展至授权范围；成绩发布按独立要求处理。

真实课程写入数与评论提交数在本次演练中均为0。批量下载ZIP、真实分数保存、真实评论提交、成绩发布、在线PDF批注仍不应标记已验收。
