# Canvas 作业批改流程设计

系统每次运行应确定模式：**演练 / 建议 / 写回**。沿用用户已经说明的模式，不重复询问。用户只要求配置或跑通流程时，默认演练；真实页面上的评分框可能自动保存，因此演练时连试填也不要做。

## 目标与完成条件

正式批改必须将已确定的分数保存到 Canvas；需要评语时必须提交评论，并在离开、重新进入学生页面后确认持久化。仅生成本地建议不代表完成正式批改。成绩保存、评论提交、成绩发布分别核验；后者是否需要操作取决于当次要求及课程设置。

本项目目前交付设计文档与演练辅助原型，尚未实现独立运行的完整批改应用。真实写回保存方式仍待首条正式验收。

## 每次输入与输出

输入：作业链接、题库或答案来源、评分规则、本次模式。概率论课程的已知默认值见 [课程配置](02-course-policy.md)，不要套用于别的课程。作业题号、学生名单、提交版本每次以当前页面为准。

输出到本次任务的本地 outputs/（不纳入版本控制）：流程报告或评分建议表，以及可续跑的 JSON 记录。真实学生结果只放本次任务，不存进项目仓库。保存来源资源页和页码，不保存登录信息、签名下载地址、临时预览链接或会话令牌。

## 流程

1. **接入及界定范围**：用当前受支持的 `cua_repl` 浏览器 API 选择 Chrome，读取文档并命名会话，列出并认领实际 Canvas 标签。复用登录；登录失效交给用户完成。确认课程、作业名、满分、题号、截止时间和已有成绩。不要依赖上次标签 ID、AX 索引或学生顺序。
2. **答案**：渲染题库 PDF 并核对页面图像，在章节末尾寻找标注“习题×答案”的二维码。脚本 [decode_qr.py](../tools/decode_qr.py) 可解码指定页的多个二维码，需按其位置和旁边标签选择。使用工具打开解码后的地址，走正常登录和资源预览。核验教材、章节、题号，实际读完所有相关答案页。只有题目时不要把自行推导冒充官方答案。
3. **提交清单**：从 SpeedGrader 学生选择器核对状态。待办数、作业页分母、学生数可能不同，分别记录来源；未提交只记状态，不擅自给零分。每个已提交学生记录稳定学生标识、提交时间、可见的提交次数和**全部附件 ID/文件名**。不能获取版本证据时标记待核验，不推断唯一版本。
4. **完整阅读**：每次切换后核对学生身份、URL 中的学生标识、提交时间、附件清单和实际预览内容。逐个附件读取所有页；封面、扫描件、超长单页均需处理。缩放与翻页用当前 UI，页码改变后仍须检查实际画面；文字层/OCR 仅辅助，数学符号以图像为准。单页可能长于视口，必须滚动到页底。无法辨认不算错；附件错题号/错章节先标记待复核，不直接按空题处罚。
5. **核对与建议**：依据本次已确认规则，按大题汇总证据，允许等价解法。每题写状态、答案页、学生附件及页、必要的扣分原因。只有覆盖完整且无歧义的提交才形成确定建议。大量未写、疑似错交、答案本身存疑等单列。不得用“基本都交了”代替阅读。
6. **记录及复核**：按 [运行记录](03-run-record.md) 保存草稿，汇总待复核项。演练只采集少量页面证据，评分计算使用明确标记的虚构样本，不输出真实学生正式分数。建议模式不写 Canvas。
7. **授权写回**：只有本次明确授权的作业、学生和结果可写入。先重读当前提交版本及已有分数/评论，与审批过的草稿对照。变更了提交或人工成绩时停止该条，不覆盖。真实分数的保存触发方式未实测，不假设“提交”按钮保存分数；该按钮位于评论区。PDF 内“保存”属于批注，不是分数保存。首次真实写回仅处理一条授权结果，离开并重进该学生后核验分数和评论，再扩大范围。
8. **恢复及收尾**：同版本、同规则、同结果且平台状态一致则跳过；版本变化重新核对；网络结果不明先回读，绝不盲目重试评论。记录局部成功，失败项单列。成绩保存、评论提交、成绩发布是不同动作；不额外点击“发布或隐藏评分”。报告确切完成数量及未完成原因。

## 已知浏览器分支

细节及验证边界见 [演练证据](04-validation.md)。使用当前工具文档，勿复制历史临时链接、令牌、进程 ID 或 locator 索引。

二维码脚本依赖 `pdftoppm`、Python `Pillow` 与 `zxing-cpp`。运行环境须提供可用 Python 和 Poppler；在 Codex 内可用 `load_workspace_dependencies` 定位运行时；缺包时安装到本次任务 `work/` 下的临时依赖目录并仅对该次脚本设置 `PYTHONPATH`，不要硬编码旧任务的依赖路径。示例：`python decode_qr.py <题库.pdf> --page 5 --pdftoppm <可执行文件路径>`。脚本只解码本地 PDF，不下载或访问登录资源。

- 出版社临时预览失效：回二维码资源原页重新生成，一次失败后再检查页面状态，不循环猜 URL。
- Canvas 原始附件下载出现 `ERR_BLOCKED_BY_CLIENT`：不绕过阻拦、不提取 Cookie；在已授权的正常 Canvas 内嵌预览完整读取。若预览也不可读则停在附件问题，不给分。
- 工具连接失败：按官方诊断处理；本项目 不擅自重启整个 Codex、修改全局代理或修改插件缓存配置。
- 页面结构不匹配时重新观察，不机械使用上次元素位置。

## 验收

区分四种证据：真实只读验证、本地模拟通过、真实写回已核验、未验证。模拟通过不能升级为真实保存/发布通过，也不代表所有学生都已批改。
